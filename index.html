Romain Boman

À propos

RunningMap est une application statique pour explorer des parcours de course, leurs traces GPX et les photos associées.

Aide rapide

  • Rechercher ou filtrer les courses avec le bouton “Recherche”.
  • Cliquer sur une course pour la sélectionner et centrer la carte.
  • Utiliser le bouton “Détails” pour afficher les informations et photos de la course sélectionnée.
  • Cliquer sur une miniature photo pour centrer la carte sur la photo.
  • Double-cliquer sur une miniature photo pour ouvrir la photo en grand.
  • Utiliser les boutons précédent/suivant dans la visualisation photo pour parcourir les images.
  • Les marqueurs “Départ” et “Arrivée” indiquent le début et la fin du parcours sélectionné.
  • Les flèches indiquent le sens du parcours sélectionné.

Crédits

  • Cartographie : Leaflet.
  • Données de fond de carte : OpenStreetMap contributors.
  • Hébergement des photos : Cloudflare R2.
  • Hébergement du site : GitHub Pages.
